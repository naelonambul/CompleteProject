# C / C++ Projects

2018–2019년 C/C++ 학습 과정에서 직접 구현한 자료구조, Windows GUI, 네트워크 프로그래밍 프로젝트 모음입니다.

각 프로젝트의 상세 README에는 구현 목적, 핵심 기능, 기술적 포인트와 현재 한계를 정리했습니다.

## Projects

### [MiniPPT](./190215-MiniPPT/README.md)
**C++ · MFC · TCP/IP · Client/Server**  
도형 생성·수정·삭제와 채팅 데이터를 TCP/IP로 주고받는 MFC 기반 네트워크 드로잉 프로그램입니다.

### [Expression Tree Calculator](./181115-calcTree/README.md)
**C · Parser · Binary Tree · Stack**  
문자열 수식을 검증·파싱하고 Binary Tree로 구성한 뒤 연산 결과를 계산하는 콘솔 프로그램입니다.

### [CMyVector](./190219-CMyVector/README.md)
**C++ · Dynamic Memory · Copy/Move Semantics · Operator Overloading**  
동적 배열의 확장과 축소, 복사·이동 생성자, 연산자 오버로딩을 직접 구현한 Vector 학습 프로젝트입니다.

### [Sort Visualization](./190104-Sort/README.md)
**C++ · MFC · GDI · Worker Thread**  
Bubble Sort의 비교·교환 과정을 GDI로 시각화하고, 작업 스레드로 정렬 중 UI 블로킹을 줄인 프로그램입니다.

### [Drag & Drop File Hash](./190220-DragAndDropTest/README.md)
**C++ · MFC · Windows API · SHA-1**  
Explorer에서 파일을 드롭하면 절대 경로와 SHA-1 해시를 계산해 표시하는 Windows 프로그램입니다.

### [Address Book](./181025-Addressbook/README.md)
**C · Linked List · File I/O · Function Pointer**  
파일에서 주소 데이터를 읽고 연결 리스트로 관리하며 추가·검색·삭제를 처리하는 콘솔 주소록입니다.

### [Mouse Drag Interaction](./181209-DragMouse/README.md)
**C++ · MFC · Windows Messages**  
마우스 이벤트와 메뉴 상태 처리를 연습한 MFC 프로젝트입니다. 현재 저장소에는 원본 소스가 누락되어 문서만 보존되어 있습니다.
